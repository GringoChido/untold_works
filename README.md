# Untold.works

The portfolio of Joshua Semolik. Vite, React 19, TypeScript, Tailwind 3, react-router, prerendered with Puppeteer, deployed on Netlify.

## Run

```
npm install
npm run dev          # vite on http://localhost:3000
npm run build        # type-check, write sitemap and llms.txt, build, prerender every route
npm run verify       # check the prerendered build against src/data/projects.json
npm run preview      # serve dist/
```

## Where things live

- `src/data/projects.json` is the source of truth for every category, project, card color, visual and fact row.
- `src/data/images.json` and `public/images/` are generated by `node scripts/build-images.mjs <source dir>` from the original jpg and svg files.
- `scripts/routes.mjs` lists every route. Prerender, sitemap and llms.txt read it.
- `public/_redirects` holds the 301 map from the old site.
- `netlify/edge-functions/auth.ts` puts the preview behind basic auth. Set `SITE_PASSWORD` on the Netlify site; any username works.
- `src/site.ts` holds the email constant (still an open item) and the `VITE_FEATURE_SCALE` flag for layer 08.
