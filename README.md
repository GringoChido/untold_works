# Untold.works

The portfolio of Joshua Semolik. Vite, React 19, TypeScript, Tailwind 3, react-router, prerendered with Puppeteer, deployed on Netlify.

The homepage introduces Untold.works and its applied AI workflow, then opens three bodies of work: Billiard Factory, Second Son Productions and related music work, and Other Projects. The Billiard Factory and music pages gather the individual cases into larger engagement stories. Capability pages remain a cross-project archive.

## Run

```
npm install
npm run dev          # vite on http://localhost:3000
npm run build        # type-check, write sitemap and llms.txt, build, prerender every route
npm run verify       # check the prerendered build against src/data/projects.json
npm run verify:seo   # validate metadata, schema, links, assets and crawl structure
npm run preview      # serve dist/
```

## Where things live

- `src/data/projects.json` is the source of truth for every category, project, card color, visual and fact row.
- `src/data/editorial.json` selects the lead engagements and project examples shown ahead of each compact supporting index.
- `src/data/images.json` and `public/images/` are generated by `node scripts/build-images.mjs <source dir>` from the original jpg and svg files.
- `assets/` keeps source-backed project renders, campaign artwork and demo screenshots used to replace text-only visuals. Run `npm run images:projects` to rebuild their WebP sets after changing them.
- `src/data/seo.json` contains reviewed titles, descriptions and social images for all 51 public routes. Metadata is written into the saved HTML and updated during navigation.
- `scripts/routes.mjs` lists every route. Prerender, sitemap and llms.txt read it.
- `scripts/write-static.mjs` generates the page/image sitemap, video sitemap, content index and redirects. Sitemap modification dates are omitted until accurate editorial dates are maintained.
- `scripts/legacy-redirects.txt` holds old URL mappings. `public/_redirects` is generated; the domain redirect must stay ahead of path rules. Never force a trailing-slash-only redirect because Netlify normalizes slashes before matching rules.
- `src/pageLoader.tsx` splits pages into separate downloads and loads the initial route before hydration. Preserve that order when changing startup code.
- `scripts/verify-seo.mjs` runs automatically at the end of every build and rejects missing metadata, invalid references, orphan pages, unsafe slash redirects and stray HTML copies.
- `public/404.html` helps visitors recover from an unknown URL while retaining its 404 status.
- `src/site.ts` holds public contact details and the `VITE_FEATURE_SCALE` flag for layer 08. Contact pages currently use email and telephone links; those links do not constitute a tested form-delivery integration.
